5) Системные ограничения

1. Технологические ограничения

· Язык реализации — C++.
· Взаимодействие с Telegram — через Bot API, используется один бот.
· Разработка ведётся на Windows (рабочие машины команды).
· Исходный код хранится в Git, платформа — GitHub (бесплатный тариф).

2. Ограничения по хостингу

· Бот должен работать круглосуточно (24/7).
· Бюджет проекта — 0 рублей.

3. Ограничения по данным

· Хранятся только Telegram ID пользователя и номер группы; персональные данные (ФИО, контакты) не сохраняются.
· Бот не формирует расписание самостоятельно, а только отображает загруженное.

4. Ограничения по срокам

· Проект должен быть завершён к концу первого семестра.

5. Ограничения по нагрузке и доступности

· Целевая аудитория — студенты факультета ИРИТ (один факультет).
· Время отклика бота — не более 2 секунд.
· Требуемая доступность — 24/7.

6. Ограничения по интерфейсу

· Взаимодействие пользователя с системой — только через Telegram.
· Отдельное приложение, сайт или веб-панель не предусмотрены.
· Управление — через команды и кнопки бота.

1. Описание
В рамках курсового проекта разрабатывается Telegram-бот, предназначенный для предоставления студентам актуального расписания занятий. Доступ к боту осуществляется через мессенджер Telegram, что не требует установки дополнительного программного обеспечения и обеспечивает удобство использования на любых устройствах.

2. Бизнес-требования
Проблема. Информация о расписании размещается на сайте вуза и в чатах групп, что затрудняет её оперативный поиск. Студенты тратят время на уточнение расписания, а сотрудники деканата — на повторяющиеся ответы и оповещения об изменениях.
Ценность для заказчика (вуза):
а) Снижение нагрузки на сотрудников деканата при информировании студентов.
б) Повышение своевременности доведения информации об изменениях в расписании.
в) Современный и удобный канал коммуникации со студентами.
Ценность для разработчиков (студентов):
г) Практический опыт разработки программного продукта.
д) Успешная защита курсового проекта и закрытие сессии.
e) Формирование навыков, применимых в дальнейшей профессиональной деятельности.
